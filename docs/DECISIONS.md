# Decisions

Each entry: what was decided, why, and what was rejected. The rejected column
matters most — it stops a future session from "improving" things back to a shape
that was already ruled out.

The 92 decisions that used to follow moved to `docs/decisions/` (one file per
decision) so a session can open exactly the one it needs -- see
`docs/decisions/INDEX.md`. This file's own git history still holds the
original text (`git log --follow -- docs/DECISIONS.md`).

Deferred / open items: `docs/decisions/OPEN.md`.
