---
description: Capture a future product idea in docs/IDEAS.md, reading nothing else
argument-hint: <idea text>
---

Append the idea to `docs/IDEAS.md`. Do not read `docs/STATE.md`,
`docs/ROADMAP.md`, or any decision file first — this command exists so an
idea can be captured mid-task without pulling in unrelated context.

1. If `docs/IDEAS.md` doesn't exist, create it with the header shown in its
   own template (see `CLAUDE.md`'s "Finding context" table).
2. Append one line at the end of the file: `- <YYYY-MM-DD> — $ARGUMENTS`
   (today's date).
3. Confirm the line was added. Nothing else — no analysis, no judgment on
   whether it belongs on the roadmap instead, no reading the rest of the
   file back.
